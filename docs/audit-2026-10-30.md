# Keyword Planner audit — 2026-10-30

## Result

The existing server was a useful read-only keyword ideas integration, but had
correctness, authentication, packaging, and test-coverage gaps. Version 0.3.0
addresses the findings below. The audit validated the local update before
publication. Publishing the release does not restart existing MCP connections.

## Findings and changes

| Area | Finding | Change |
| --- | --- | --- |
| Dependencies | Locked Google Ads SDK 29.2.0 and MCP 1.26.0 | Installed and tested Google Ads 35.0.0 / API v26 and MCP 1.30.0; refreshed transitive dependencies |
| Reproducibility | Lockfile ignored; CI resolved dependencies again | Include `uv.lock`; CI/release use locked installs |
| Historical research | Existing historical tool expands seeds into new ideas | Added `keyword_historical_metrics` for up to 10,000 supplied keywords, preserving the existing ideas tool |
| Missing data | Absent optional volume, CPC and bid fields appeared as zero | Preserve absence as `null`; retain reported zeroes |
| Pagination | Automatic iteration could cross a short page while returning its original token | Return precisely one API page and its continuation token |
| Protobuf modes | Raw protobuf enums could appear as numbers | Read enum names through SDK descriptors; test both supported modes |
| Interpretation | Targeting and metric semantics absent from responses | Echo targeting; clarify approximate volume, advertiser competition, and customer-account currency |
| Inputs | Excess seeds/locations and malformed URLs/IDs reached the API | Validate limits, deduplicate exact duplicate seeds/locations, reject malformed URLs/IDs; allow explicit worldwide locations |
| OAuth disclosure | Manual exchange returned the refresh token in chat | Return success/persistence status without the secret |
| Token storage | Token file written before private permissions were applied | Atomic replacement using a private temporary file; tolerate malformed token files |
| OAuth callback | Invalid state ended the flow; server sockets were not closed | Reject invalid state without cancelling; add PKCE, expiry, single-use callback handling and port cleanup |
| Reliability | No explicit RPC timeout | 30-second RPC timeout; bounded retries for transport failures, excluding auth/quota errors |
| Documentation | `.env` quickstart did not load the file; stale one-tool package description | Correct startup command, tool selection, compatibility notes and packaging metadata |
| Releases | Publishing jobs rebuilt artifacts after validation | Publish the same distributions produced by the test/build job |

MCP remains intentionally on the compatible 1.x SDK line; this update does not
claim migration to the newer 2.x API. Existing targeting defaults remain English,
US, and Search and Partners. German Switzerland requires explicit language 1001
and location 2756. CPC is available as an option on all idea seed tools.

## Verification

- 66 tests passed locally on Python 3.13, including real v26 SDK messages in both
  protobuf modes and real loopback OAuth callbacks with fake credentials.
- MCP stdio handshake, all ten tool schemas, read-only keyword annotations, and
  structured missing-configuration errors passed.
- Source compilation, focused Ruff checks, formatting and diff checks passed.
- Wheel and source distribution built; package metadata checked with Twine.
- `pip-audit` reported no known vulnerabilities in the locked runtime dependency
  set applicable to the local environment. This is not a guarantee of no flaws.
- CI configured for Python 3.10, 3.13 and 3.14; remote CI has not run in this audit.

## Boundaries and compatibility

A live Google Ads request remains unverified because developer token, OAuth client
ID and client secret are absent from this workspace's process environment. The
connected MCP service is a separate running instance; local changes do not update
it automatically. Public release and reconnect/restart are separate deployment steps.

Consumers must accept nullable metrics, additional response metadata and the
removal of `refresh_token` from the OAuth tool response. Pagination now returns
up to one API page, which may be shorter than the requested page size. The manual
OAuth code-copy fallback remains available; prefer the local PKCE callback flow.

This server covers keyword ideas and historical metrics. It is not a complete
replacement for every Google Ads planning feature: forecasts and automatic ad-group
organization remain outside the implemented tool set. No Ads campaigns are modified.
